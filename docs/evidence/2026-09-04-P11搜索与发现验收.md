## 4. 功能边界与回滚边界

- 搜索首期只覆盖标题、正文、地点名和作者昵称；不包含标签、推荐算法、Elasticsearch 或搜索结果 Redis 缓存。
- `q` 会去除首尾空白并限制 2~64 个 Java 字符；`%`、`_`、反斜杠按字面匹配；结果实时过滤公开笔记、非删除状态和正常作者。
- `recent` 使用 `created_at DESC, id DESC`；`relevance` 使用标题 4、地点 3、作者 2、正文 1 的命中分，再按时间和 id 稳定排序；cursor 绑定 query/sort。
- `highlight` 为服务端生成的纯文本摘录，前端使用文本插值，不使用 `v-html`；本轮未执行实体 NVDA/JAWS 读屏器审计。
- V6 是只增加读路径索引的前向迁移；`ops/rebuild-search-index.ps1` 只做 `ANALYZE/EXPLAIN`，不改业务数据。若需回滚，走已有备份恢复或经评审的后续反向迁移，不直接修改已应用的 Flyway 文件；本轮未对业务库执行回滚。
