## 3. 实现内容与验证

### P15-01 写接口限流基线

- 新增 `common.RateLimitService`（Redis INCR+EXPIRE 滑动窗口，`ErrorCode.TOO_MANY_REQUESTS/42001`），阈值经 `SCENARY_RATELIMIT_*` 可配；接入注册（按 IP）、发笔记 30/10min、点赞/收藏/关注 120/min、图片上传 60/10min；评论 20/min 契约不变改为复用该服务。
- IP 归因修正：nginx `/api/` 增加 `X-Forwarded-For $proxy_add_x_forwarded_for`，`AuthController.clientIp` 改取 XFF **末段**（本方反代追加段，防伪造），回环客户端豁免注册限流（可经 `SCENARY_RATELIMIT_EXEMPT_LOOPBACK` 关闭）。Compose 演示/验收默认注册阈值 200/h（`.env` 可收紧，`.env.example` 已登记）。
- 黑盒（`node docs/dev/test-p15-security.mjs`，经 `:8081`）：② 社交 125 连发 `{"404":120,"429":5}` 第 121 次触发；③ 评论 22 连发触发 429（既有契约回归）；⑤ 注册 201 次触发 429、`redis-cli` 清理 `rl:register:*` 后恢复。
- JUnit：`RateLimitServiceTest`（阈值/回环豁免/豁免关闭/降级放行）、`ClientIpTest`（XFF 末段/伪造段忽略/回退链）、`AuthServiceTest` 扩展（注销态登录 40301、吊销门面）。

### P15-02 安全响应头

- nginx server 级 + 静态资源 location 内（阻断继承补偿）增加 `X-Frame-Options: DENY`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: strict-origin-when-cross-origin`、`Content-Security-Policy-Report-Only`（含 `report-to` 指令与 `Report-To` 头，报告由 `location = /csp-report` 返回 204 丢弃收集）。
- 缺陷修复实录：WebKit 将"Report-Only 缺少 report-to"记为 console error，被既有"console 无错误"浏览器断言捕获；补齐 report-to/Report-To 后三浏览器全绿。
- 验证：黑盒 ① 断言四头齐全 + http 形态无 HSTS（预期）；三浏览器 Playwright 6/6。

### P15-03a 密码找回（运维脚本过渡）

- 新增 `ops/reset-user-password.ps1`：本机 jshell + spring-security-crypto 生成 BCrypt（仓库位置经 `mvn help:evaluate` 动态解析），`docker compose exec` 在 mysql 容器执行 UPDATE；支持 `-Preview` 干跑与 `-Reactivate` 恢复注销/禁用账号；支持自定义 Maven localRepository，回退 `~/.m2`。
- 端到端实测：注册 `p15ops_*` → 脚本重置为 `NewPass99887` → 旧密码登录 `40000`、新密码登录 `code=0`。

### P15-04 账号注销

- 后端：`DELETE /api/v1/users/me`（密码二次确认 40300）→ `AccountDeactivationService` 同事务完成用户匿名化（status=2、昵称"已注销用户"、清 bio/头像）、笔记/评论批量软删、头像对象删除；事务提交后 `AuthService.deactivateSessions` 吊销刷新白名单并落注销态缓存；拦截器每请求经 `auth:ustatus:{userId}` 缓存判定，其余设备令牌即时失效。`username` 保留占用；公开主页/笔记详情对注销用户 40400。
- 施工坑实录：首次在 `UserService` 直接注入 `CommentService` 造成 `userService ↔ commentService` bean 环，backend 重启循环；拆出单向的 `AccountDeactivationService` 解耦，学习沉淀见 [21-P15限流归因与账号注销的bean环](../learning/21-P15限流归因与账号注销的bean环.md)。
- 前端：个人中心新增"注销账号"危险区（密码确认弹层，`forceLogout` 后回首页）；Vitest 新增 2 用例（密码错误不登出、成功清理会话回首页）。
- 黑盒 ④ 六项断言：40300/200/旧令牌 401/登录 40301/笔记 404/主页 404 全部通过。

### P15-05 通知生命周期

- 验证：JUnit `purgeBatchesUntilExhaustedAndDryRunCountsOnly`（分批至尽 + dry-run 统计）；黑盒 ⑥ 断言容器环境注入 `RETENTION_DAYS=90 / CLEANUP_ENABLED=true`；dry-run 统计口径经 `countOldReadNotifications` 门面暴露。

## 5. 回滚

- 限流：`SCENARY_RATELIMIT_*` 调宽或 `SCENARY_RATELIMIT_EXEMPT_LOOPBACK` 调整，无需回滚代码。
- 响应头：逐项移除 nginx `add_header`；CSP 处于 Report-Only 无阻断风险。
- 注销：接口为显式动作无后台批处理；已注销账号恢复 = `ops/reset-user-password.ps1 -Reactivate`（或 SQL 置 status=1）。
- 通知清理：`SCENARY_NOTIFICATION_CLEANUP_ENABLED=false` 即停。

## 6. 边界与待办

- **P15-03b（email + SMTP 邮件找回）延后**：依赖外部 SMTP 凭据与 `spring-boot-starter-mail`（01 §3.1 已登记评估行），当前以运维重置脚本过渡，03 附 10 保持该项未勾。
- CSP 处于 Report-Only 观察期，`/csp-report` 丢弃式收集；enforce 化（移除 `-Report-Only`）需先盘点 index.html 两处内联脚本，属后续小任务。
- HSTS 未开启（http 开发形态不适用）；启用 TLS 的部署形态需另行开启并补验收。
- 注销后点赞/收藏/关注关系与既有通知按契约保留（计数语义与禁用账号一致）；如需物理清理属运维动作。
