## 5. 边界与已知限制

1. **marker 无聚合**：单视野上限 20 条 + "加载更多"，不做聚合抽稀（进入条件：真实数据量出现性能信号后另行立项）。
2. **web 套件偶发**：p12-e4 ④ webkit 偶发降级断言超时（已加宽至 8s，残余概率约 1/7 组合轮），chromium/firefox 稳定；归因 learning 25。
3. **CI（ubuntu 真栈）**：本轮起 e2e 跑在真实 Compose 栈上；此前 5269487 的 "Compose stack up" 失败原因待新 workflow 的 `::error::` 诊断注解回传后闭环（本地 Windows 与容器 Linux 双环境均已全绿）。
4. E4 验收报告中的瓦片域表述（OSM）已被 E5 决策覆盖：默认源切换为高德，OSM 降级为可覆盖项——以本报告与 05 §15 为准。
