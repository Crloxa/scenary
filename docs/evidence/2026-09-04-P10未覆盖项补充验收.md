## 4. 边界与风险

- 敏感词是可配置的轻量子串词表，只负责评论写入拦截；分词、变形绕过、审核状态机、人工处置和人物检测仍属于 P13，不将本项包装为完整内容审核。
- WebSocket 只传递不含正文的刷新信号；通知 HTTP 分页仍是可靠数据源。服务端使用事务 AFTER_COMMIT 推送，断线后前端有限重连并保留轮询降级。
- Playwright 的 P10 页面专项使用 mock WebSocket，避免本地 Vite 没有后端时产生代理噪声；真实 Nginx/WebSocket 链路由 test-p10-realtime.mjs 覆盖。三浏览器测试是可访问性语义和键盘专项，不等同于 NVDA、JAWS 等实体读屏器的完整人工审计。
- 压测只覆盖 /ping 和 GET /notifications?limit=1，账号注册是一次性夹具动作，不压测评论写入、数据库锁竞争、MQ、MinIO、长连接规模或公网 TLS；15561 请求结果是本机 Docker 单实例基线，不能外推生产容量。
- 压测脚本在样本为空、任一请求失败或压测后健康检查失败时返回非零退出码；当前运行错误率为 0。
