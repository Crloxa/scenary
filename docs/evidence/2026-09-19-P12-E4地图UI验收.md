## 4. 边界与已知限制

1. **坐标精度模糊化**（07 §2.2 设计注记）：发布页已有 place_precision（EXACT/APPROXIMATE）UI 选项，存储端取整模糊化涉及契约与既有 V7 数据语义，按 07 建议维持"E4 设计输入、不阻塞立项"，待 E5 前评估。
2. **真实瓦片未出网验证**：验收用 mock 瓦片；生产默认 OSM 公共瓦片需出网（01 §3.1 行已声明），离线瓦片为可选替代未准备——降级路径已实证。
3. **E2E 媒体夹具三重坑**（WebKit WMF 绕过拦截 / Chromium PNA 拦回环 / 假 Range 服务）：p12-video.spec 改为按浏览器分策略的媒体夹具（chromium/firefox 同源 /minio 拦截 mock；webkit 用 spec 内本地真 Range HTTP 服务 + 详情文档剥 CSP Report-Only 头）；详见 learning 26。组合矩阵曾受"同步断言 × 定时器节流"影响（E3-③），改 `expect.poll` 后 5×36/36 连绿（learning 25 补强条目）。
4. 会话期间 ms-playwright 浏览器缓存曾被外部清理导致 36 连挂（启动失败非用例失败），重装后恢复——证据轮转失败判定时已排除该噪音。
